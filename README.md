# Retail_Sales_EDA_Project


📌. Project Overview
This project is about analyzing retail sales data using Python. It helps us understand sales trends, customer details, and product performance. I used charts and graphs to make the data easier to understand.


📌. Project Objectives
- To understand retail sales data.
- To clean the data and remove duplicate records.
- To find sales trends and popular products.
- To study customer age groups and product categories.
- To help businesses make better decisions.

📌. Dataset
The project uses a retail sales dataset stored in a CSV file. It contains details such as order ID, order date, customer ID, gender, age, region, category, product name, quantity, sales, profit, and discount.

📌. Tools and Technologies
- **Python:** To analyze the data.
- **Pandas:** To load, clean, and organize the data.
- **NumPy:** To perform numerical operations.
- **Matplotlib:** To create charts and graphs.
- **Seaborn:** To create visualizations and understand relationships between data.
- **VS Code and Jupyter Notebook:** To write and run the code.

📌. Data Cleaning
I checked the dataset for missing values and duplicate records. I removed duplicate rows and converted columns into the correct data types where needed. I also checked numerical columns to prepare the data for analysis.

📌. Key Business Insights
- Monthly and quarterly sales charts help identify changes in sales over time.
- Product analysis helps identify the most popular products.
- Category-wise sales analysis shows which product categories generate more sales.
- Customer age-group and gender analysis helps understand customer demographics.
- Sales and profit analysis helps identify areas where business performance can improve.


📌. Project Structure
- `Retail_Sales_EDA/` – Main project folder.
- `retail_sales_dataset.csv.csv` – Original dataset.
- `retail_sales_dataset.ipynb` – Notebook containing the analysis and visualizations.
- `cleaned_retail_sales.csv` – Cleaned dataset saved after data cleaning, if created.
- `requirements.txt` – List of required Python libraries.
- `README.md` – Project description and instructions.
- `outputs/` – Folder for saved charts and reports, if created.

📌. Project Outcome
Through this project, I learned how to clean and analyze retail sales data using Python. I created visualizations to understand sales trends, customer groups, and product performance. The analysis can help businesses make better decisions about products, inventory, and sales strategies.
