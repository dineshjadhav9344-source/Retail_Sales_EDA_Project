# Retail_Sales_EDA_Project
1. This project analyzes retail sales data using Python, Pandas, NumPy, Matplotlib, and Seaborn.
2. Data cleaning is performed to handle duplicate records, missing values, and incorrect data types.
3. Exploratory Data Analysis (EDA) helps understand sales trends, customer age groups, and product performance.
4. Visualizations such as bar charts, line charts, pie charts, and heatmaps help identify useful patterns.
5. The project provides business insights to improve inventory planning, sales strategies, and profit management. convert natural and simple language
